# Evaluation starter

Use `questions_template.csv` to build a small benchmark from the PDFs you actually index. Aim for 30–50 questions, including:

- Answerable questions that point to different pages and topics in the source set
- Questions phrased in English and Tamil, if both are part of the demo
- Questions whose answer is absent from the documents and should be refused
- A few misleading or off-topic questions to check that retrieval does not force an answer

For each answerable item, record the expected source filename and PDF page. Score the system output against the source passage, not against an answer generated by another chatbot. Keep the original question set fixed when comparing versions.

## Suggested measures

- **Retrieval accuracy:** answerable questions where at least one expected source passage was retrieved, divided by answerable questions.
- **Answer accuracy:** answerable questions whose key facts match the source, divided by answerable questions.
- **Citation correctness:** citations that support the nearby claim, divided by citations reviewed.
- **Refusal accuracy:** unanswerable questions refused without unsupported health claims, divided by unanswerable questions.

Do not publish a score until the questions have been run and manually reviewed. Report the sample size and how the questions were selected alongside any result.
